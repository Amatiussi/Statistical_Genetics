# Statistical Genetics I: Foundations

This repository contains the materials for the course `LGN5822 - Statistical Genetics I (2026)`, taught by `Prof. Dr. Saulo Fabrício da Silva Chaves` at ESALQ/USP, as part of the Graduate Program in Genetics and Plant Breeding. The purpose of this repository is to provide access to the `scripts` and `exercises` developed throughout the classes of the current semester, all written in R.
